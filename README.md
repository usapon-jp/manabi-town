# まなびタウン

子どもが自分で宿題やテストを管理し、勉強した分だけ自分の街が育つ家庭教師アプリ。
いまはお試し版で、草原でピヨちゃん（ピヨ先生）と勉強してポイントを貯めるところまで。

## お試し版でできること

- **きょうやること**（ホーム）: テスト・宿題・目標を入れると、しめきりまでの日数で毎日の分に自動でわける。ページ（p.40〜52 など）を書くとページごとにわける。1つできたら +10。サボった日の分は次の日から配り直す（`js/planner.js`）
- **やること**: テスト・宿題・目標を登録。宿題を出したら +20、テストや目標が終わったら +50 ポイント
- **チュートリアル**: はじめて開いたとき、指と光る輪でタップする場所を見せる（`js/tutorial.js`）。せっていから見直せる
- **クエスト**: 毎日の漢字・英単語・算数を3問ずつ。正解1問10ポイント、全問正解で +30
  - 漢字は書き2問＋読み1問。読みを見てノートに書き、「こたえを見る」でお手本を出して、書けた／書けなかったを自分でつける（自動の答え合わせは Claude API とつないでから）
  - 算数は方眼のメモ欄に指で筆算できる
  - 手書きはうさぽんメモのエンジン（`js/ink/input.js`・`stroke.js`）をそのまま使う。ペン優先・手のひら無視・2本指タップで1つもどす
- **タイマー**: 勉強した時間を計る。1分1ポイント、決めた時間までやりきると +10。種類（宿題・チャレンジ・自主学習・テスト勉強）と教科をえらび、あとから記録を直したり消したりできる。きょう・今週・るいけいの分数と、教科ごとの週グラフを出す。とちゅうで閉じても続きから計れる（`js/timer.js`）
  - BGM: たまの勉強タイマーと同じ標準4曲、スマホの曲や動画（音だけ取り出す）、前のタイマーで取り込んだ曲（同じブラウザならそのまま見える）、前のタイマーの書き出しファイル（`js/bgm.js`）
- **🎁 ボーナス**（上のバー）: もっとポイントがほしいときに選べる追加のクエスト（`js/bonus.js`）
  - 「きょうのおすすめ」「すすみ表」は見るだけで +3（1日1回ずつ。🔥の日数には数えない）。ピヨの顔をタップ→おすすめ、0/2 をタップ→すすみ表でもひらける
  - 漢字・英単語・計算のドリル5もん（1日1回ずつ、1もん5・ぜんぶで +10）、タイマー30分で +15
  - 今週のイベント: スタンプ5日・120分・まいにちクエスト5回。できたら「うけとる」
- **小テスト**: 「とりこみコード」で入れた問題。8割正解でクリア
- **ホーム**: 草原の3D箱庭。うさぽん村と同じ形のスティックでピヨちゃんを動かせる（丸の外まで引くとスタスタ）。ジャンプ（空中でもう1回）とダッシュ（1回おすと開始、もう1回かスティックをはなすと止まる）。パソコンは WASD・スペース・Shift。タップした場所へ歩く、ドラッグで向きを変える、も使える（`js/controls.js`）
- **つくる**（ホームの右がわ）: 子どもが草原を自分で作りかえる（`js/editor.js`・`js/builds.js`・`js/cutmask.js`）
  - **みち**: 指でなぞった形に草がかられて、土の道になる（太さ3段）
  - **はな**: 好きな場所に5種類の花をうえる／なぞった形を丸太か石でかこんで花だんにする
  - **かわ**: 地面をほって川（ながれ）や小さな池をつくる。同じ場所を3回ほると水がわき、そこへつながった溝にも水がながれこむ（町の池にもつなげられる）。水はかんたんな水面
  - 1つずつ「もどす」で取り消せる。操作のたびに自動保存され、きょうだい（プロフィール）ごとに別の草原になる（保存は点と種だけで小さい）
- **せってい**: きょうだいの切り替え、学年の変更、とりこみ

**向き**: スマホを横にすると、ホームは両手で遊ぶ配置になる（タブは左にしまい ☰ で出す。左上は小さな「つぎはこれ！」だけ）。勉強の画面は左にタブが立ち、並びは縦と同じ。タイマーは時計が左、ボタンが右。iPad は縦と同じ配置のまま（`css/style.css` のいちばん下）。

データはこの端末のブラウザ（localStorage）にだけ保存される。

## 動かし方

ビルドは不要。静的ファイルをそのまま配信する。

```sh
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

GitHub Pages で `main` のルートを公開すればそのまま動く。three.js は `vendor/three/`（0.170.0）に同梱している。

公開先: https://usapon-jp.github.io/manabi-town/ 。スマホで開いて「ホーム画面に追加」するとアプリとして使える（`manifest.webmanifest`、アイコンは `assets/icons/`）。
`sw.js` が部品を端末にしまうので、ネットがなくても開ける。部品を増やしたら `sw.js` の `FILES` に足して `VERSION` を上げる。

## AI 料金の記録

- AI（Claude API）を呼ぶたびに、受け口 `manabi-ai` が「機能・使った人（子どもは学年だけ、おとなは「おとな:ハンドルネーム」）・モデル・トークン数・推定料金」を Supabase の `ai_usage` 表に残す（子どもの名前や勉強の中身は入れない）。表は `supabase/migrations/20261102120000_ai_usage.sql`
- 料金表と月の上限（シークレット `AI_MONTH_LIMIT_USD`、なければ $5）は `supabase/functions/_shared/usage.ts`。Anthropic の残高は API で読めないので、記録した推定額で判断する
- せってい →「ピヨ先生のヒント（AI）」に今月の料金と月末の見込みが出る
- `manabi-usage` は数字だけを返す読み取り専用 URL（`?k=合言葉`、`&f=json` で JSON）。合言葉はシークレット `USAGE_TOKEN`。`verify_jwt=false` でデプロイし、Muse などのエージェントに定期的に開いてもらって 70%・90% をこえたら知らせてもらう

## キャラを差し替える

`assets/models/` に GLB を置き、`js/characters.js` に1つ足して名前と骨の対応を書く。
骨の名前は記号を無視して比べるので、`mixamorig:Hips` と `mixamorigHips` は同じに扱う。
アニメーションは GLB に入っていなくてよく、骨をコードで動かす。

## とりこみコードの形

プリントの写真から Claude が作る JSON。アプリの「せってい」→「とりこみ」に貼る。

```json
{
  "manabi": 1,
  "items": [
    { "type": "test", "subject": "理科", "title": "電気のはたらき 小テスト", "range": "教科書 p.40〜52", "date": "2026-11-10" },
    { "type": "homework", "subject": "国語", "title": "漢字ドリル p.12〜15", "date": "2026-11-04" }
  ],
  "quizzes": [
    {
      "title": "電気のはたらき",
      "subject": "理科",
      "questions": [
        { "q": "電池を直列つなぎにすると、モーターの回る速さは？", "options": ["速くなる", "おそくなる", "変わらない"], "answer": 0 },
        { "q": "1.5V のかん電池2こを直列につなぐと何ボルト？", "answer": 3 }
      ]
    }
  ]
}
```

- `type` は `test`・`homework`・`goal`（目標）、`date` は `YYYY-MM-DD`
- 選ぶ問題は `options` と、正解の番号（0から）を `answer` に書く
- 数字で答える問題は `options` を書かず、`answer` に整数を書く
