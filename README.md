# まなびタウン

子どもが自分で宿題やテストを管理し、勉強した分だけ自分の街が育つ家庭教師アプリ。
いまはお試し版で、草原でピヨちゃん（ピヨ先生）と勉強してポイントを貯めるところまで。

## お試し版でできること

- **きょうやること**（ホーム）: テスト・宿題・目標を入れると、しめきりまでの日数で毎日の分に自動でわける。ページ（p.40〜52 など）を書くとページごとにわける。1つできたら +10。サボった日の分は次の日から配り直す（`js/planner.js`）
- **やること**: テスト・宿題・目標を登録。宿題を出したら +20、テストや目標が終わったら +50 ポイント
- **チュートリアル**: はじめて開いたとき、指と光る輪でタップする場所を見せる（`js/tutorial.js`）。せっていから見直せる
- **クエスト**: 毎日の漢字・英単語・算数を3問ずつ。正解1問10ポイント、全問正解で +30
  - 漢字は書き2問＋読み1問。読みを見てノートに書き、「こたえを見る」でお手本を出して、書けた／書けなかったを自分でつける（自動の答え合わせは Claude API とつないでから）
  - 算数は方眼のメモ欄に指で筆算できる
  - 手書きはうさぽんメモのエンジン（`js/ink/input.js`・`stroke.js`）をそのまま使う。ペン優先・手のひら無視・2本指タップで1つもどす
- **タイマー**: 勉強した時間を計る。1分1ポイント、決めた時間までやりきると +10。種類（宿題・チャレンジ・自主学習・テスト勉強）と教科をえらび、あとから記録を直したり消したりできる。きょう・今週・るいけいの分数と、教科ごとの週グラフを出す。とちゅうで閉じても続きから計れる（`js/timer.js`）
  - あとから たす: タイマーを うっかり 消したときは「きょうの記録」の「＋ あとから たす」で、きょう・きのうの 分を 入れられる（1分1ポイント・やりきりの +10 なし・1日 90分まで・記録に「あとから」と出る）。とちゅうで「やめる」を おすと「◯分 記録して おわる／つづける／記録しないで けす」を えらぶ画面が出る
  - BGM: えらぶ画面は ①ながしかた（1きょくだけ・じゅんばん・シャッフル）→ ②プレイリスト（名前をつけて12こまで作れる・なまえをかえる・けす）→ ③曲（1きょくだけは1つタップ、ほかは ✓ をつける）。たまの勉強タイマーと同じ標準4曲、スマホの曲や動画（音だけ取り出す）、前のタイマーで取り込んだ曲（同じブラウザならそのまま見える）、前のタイマーの書き出しファイル（`js/bgm.js`）
- **🎁 ボーナス**（上のバー）: もっとポイントがほしいときに選べる追加のクエスト（`js/bonus.js`）
  - 「きょうのおすすめ」「すすみ表」は見るだけで +3（1日1回ずつ。🔥の日数には数えない）。ピヨの顔をタップ→おすすめ、0/2 をタップ→すすみ表でもひらける
  - 漢字・英単語・計算のドリル5もん（1日1回ずつ、1もん5・ぜんぶで +10）、タイマー30分で +15
  - 今週のイベント: スタンプ5日・120分・まいにちクエスト5回。できたら「うけとる」
- **ガチャ**（上のバーのカプセル）: ガチャ石1こで1回。石は 毎日1回のログインボーナス・レベルアップごと・ポイント100とこうかん で手に入る（`js/gacha.js`、数字と中身は `js/data/gacha.js`）
  - 1回と10連の2つのひき方。まだ持っていないものから出る（かぶらない。のこりが10より少ないときは「まとめて N回」）。でやすさ ★1:★2:★3 = 60:30:10
  - 中身の表は 3Dの箱庭の もちもの台帳もかねる（`js/catalog.js` → `ownedOfKind` / `isOwned`）。3Dができていないものは `ready: false` でガチャに出さない
  - 「あつめた もの」の絵は 3Dモデルから前もって撮った `assets/gacha/<id の : を - に>.webp`（192px）。まだのものは同じ絵のかげ（シルエット）。絵がないものは `svg` の線の絵。パーツを足したら `tools/gacha-thumbs.html` をローカルで開いて絵を作り、webp にして置く（sw.js の FILES にも足す）
  - 中身をふやす・キャラを足すときは `js/data/gacha.js` に1行足すだけ（`kind: 'chara'` でキャラ）
  - 石の数は 記録（ログインした日・こうかん・ひいた回数・レベル）から計算するので、端末をまたいでも ずれない
- **英語の読み上げ**: 英単語の問題で 単語の横のスピーカーを押すと読み上げる（端末の音声・無料）。続けて押すとゆっくり（`js/runner.js`）
- **小テスト**: 「とりこみコード」で入れた問題。8割正解でクリア
- **ながれ動画**（やること → ながれ動画）: 社会の 紙芝居（`js/story.js`）と、理科の 動画「電流と磁界（中2）」（`js/video.js`）
  - 理科は mp4 を 全画面で 再生。チャプターの ボタンで その場面へ とぶ。見おわると 学習メニューへ
  - 学習メニュー: かくにん（12もん）・れんしゅう（11もん）・しあげテスト（12もん）。小テストと 同じく 8割正解で クリア・1もん10ポイント（はじめての クリアだけ）。まちがえた問題は やりなおしに 入り、見直す 動画の 時刻が 出る
  - 問題は 学習ガイド（`assets/print/`の PDF）の 番号と そろえてある（`js/data/science-magnet.js`）。記述問題と 50点の しあげテストは プリントで
  - 動画（`assets/video/denryu-jikai.mp4`）は 大きいので `sw.js` で しまわない（シークの Range も そのまま 通す）
- **町の女の子**: 主人公は女の子。はじめて町を開いたとき（いま使っている子も1回だけ）ピヨ先生が「この子に なまえを つけてね」と聞く。名前はきょうだいの名前とは別で、せっていの「まちの 女の子」で変えられる。ピヨ先生は女の子のうしろをついてきて、タップすると「まちの つかいかた」を聞ける（`js/avatar.js`・`js/avatar3d.js`・`js/avatarname.js`）
  - 保存は `p.avatar = { name, wear, colors }`（部品のidと色の名前だけ）。体・髪・服・くつは同じ台帳 `PARTS` に1行ずつ
  - 3Dモデルの差しかえ: GLB を `assets/models/` に置き、`js/avatar.js` の体の行の `model` にパス、髪・服・くつの行の `mesh` に GLB の中のメッシュ名を書く（sw.js にも足す）。骨は Mixamo の名前。モデルがないあいだはコードで作った仮のすがたで出る
  - いまの体は きゃらくるで作った 4頭身の「カーディガン版」（`assets/models/girl.glb`、VRM から 形を減らし 絵を1024pxにした 約5MB）。骨は VRM の名前（J_Bip_…）。VRM は 骨の向きが ばらばらなので、`boneSpace: 'model'` で 関節を モデルの 前・左・上の 向きで まわす（`rest` で Tポーズの うでを 下ろす）。髪・服は モデルに 入っていて、着せ替え・色がえは まだ 効かない。髪の揺れ（spring bone）も なし
  - たしかめ: `node --experimental-default-type=module tools/avatar-checks.mjs`
- **教科のたまご**: 名前とチュートリアルのあと、ピヨ先生から5教科のたまごをもらう（町のまんなかの巣）。放っておいても7日、その教科を10分勉強するごとに半日すすむ（タイマーの記録と、きょうのクエスト1パーツ=5分）。もらう前の勉強の分だけ少し温まっている（上限2.5日）。のこりは数字で出さず「もうすぐかも…」。勉強すると次に町を見たとき、たまごが光ってゆれる・たねにじょうろで水（`js/eggs.js`・`js/eggs3d.js`・`js/eggui.js`）
  - 孵化すると教科のなかま（ふくろう・リス・モグラ・キツネ・ウサギ）が生まれ、建物のたねをくれる。女の子の前の わっか で場所をきめてうえる → 芽 → つぼみ → 建物（図書館・銀行・発電所・市場・空港）。たねは放っておいて5日、10分で半日
  - 保存ははじまりの島の入れ物 `p.world.isles.start.eggs`（もらった時刻・孵化・うえた場所・できた時刻だけ）。すすみは時刻と勉強の記録から毎回計算するので、端末どうしでずれない。ポイント・レベル・町の ops にはさわらない
  - 数字（日数・10分で半日 など）は `js/eggs.js` の `TUNE` に まとめてある
  - しくみの入口: 孵化で ひらくしくみは `UNLOCKS`（理科→カメラ・夜の灯り、算数→銀行、国語→図書館、社会→アルバム・市場、英語→観光）。しくみのスレッドは `featureOpen(p, 'camera')` で ひらいたかを見て、`registerFeature('camera', { label: 'カメラ' })` で名前を登録すると孵化カードに「カメラが つかえるよ」と出る。`onFeatureOpen` で ひらいた瞬間も受けとれる
  - なかまの3Dモデルの差しかえ: GLB を `assets/models/` に置き、`js/eggs.js` の `EGGS` の `chara.model` にパスを書く（sw.js にも足す）。ないあいだは教科の色の まるい仮のすがた
  - おとなは ジャンルの はじめの5つにつながる。たまごのカードで「つなげる べんきょう」を えらびなおせる
  - たしかめ: `node --experimental-default-type=module tools/egg-checks.mjs`
- **ホーム**: 草原の3D箱庭。うさぽん村と同じ形のスティックで女の子を動かせる（丸の外まで引くとスタスタ）。ジャンプ（空中でもう1回）とダッシュ（1回おすと開始、もう1回かスティックをはなすと止まる）。パソコンは WASD・スペース・Shift。タップした場所へ歩く、ドラッグで向きを変える、も使える（`js/controls.js`）
- **つくる**（ホームの右がわ）: 子どもが草原を自分で作りかえる（`js/editor.js`・`js/builds.js`・`js/cutmask.js`）
  - **みち**: 指でなぞった形に草がかられて、土の道になる（太さ3段）
  - **はな**: 好きな場所に5種類の花をうえる／なぞった形を丸太か石でかこんで花だんにする
  - **かわ**: 地面をほって川（ながれ）や小さな池をつくる。同じ場所を3回ほると水がわき、そこへつながった溝にも水がながれこむ（町の池にもつなげられる）。水はかんたんな水面
  - 1つずつ「もどす」で取り消せる。操作のたびに自動保存され、きょうだい（プロフィール）ごとに別の草原になる（保存は点と種だけで小さい）
- **せってい**: きょうだいの切り替え、学年の変更、とりこみ

**向き**: スマホを横にすると、ホームは両手で遊ぶ配置になる（タブは左にしまい ☰ で出す。左上は小さな「つぎはこれ！」だけ）。勉強の画面は左にタブが立ち、並びは縦と同じ。タイマーは時計が左、ボタンが右。iPad は縦と同じ配置のまま（`css/style.css` のいちばん下）。

データはこの端末のブラウザ（localStorage）にだけ保存される。

## 動かし方

ビルドは不要。静的ファイルをそのまま配信する。

```sh
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

GitHub Pages で `main` のルートを公開すればそのまま動く。three.js は `vendor/three/`（0.170.0）に同梱している。

公開先: https://usapon-jp.github.io/manabi-town/ 。スマホで開いて「ホーム画面に追加」するとアプリとして使える（`manifest.webmanifest`、アイコンは `assets/icons/`）。
`sw.js` が部品を端末にしまうので、ネットがなくても開ける。部品を増やしたら `sw.js` の `FILES` に足して `VERSION` を上げる。

## AI 料金の記録

- AI（Claude API）を呼ぶたびに、受け口 `manabi-ai` が「機能・使った人（子どもは学年だけ、おとなは「おとな:ハンドルネーム」）・モデル・トークン数・推定料金」を Supabase の `ai_usage` 表に残す（子どもの名前や勉強の中身は入れない）。表は `supabase/migrations/20261102120000_ai_usage.sql`
- 料金表と月の上限（シークレット `AI_MONTH_LIMIT_USD`、なければ $5）は `supabase/functions/_shared/usage.ts`。Anthropic の残高は API で読めないので、記録した推定額で判断する
- せってい →「ピヨ先生のヒント（AI）」に今月の料金と月末の見込みが出る
- `manabi-usage` は数字だけを返す読み取り専用 URL（`?k=合言葉`、`&f=json` で JSON）。合言葉は表 `app_secret`（name=`usage_token`）に SHA-256 で置く（シークレット `USAGE_TOKEN` があればそちらを優先）。`verify_jwt=false` でデプロイし、Muse などのエージェントに定期的に開いてもらって 70%・90% をこえたら知らせてもらう

## キャラを差し替える

`assets/models/` に GLB を置き、`js/characters.js` に1つ足して名前と骨の対応を書く。
骨の名前は記号を無視して比べるので、`mixamorig:Hips` と `mixamorigHips` は同じに扱う。
アニメーションは GLB に入っていなくてよく、骨をコードで動かす。

## とりこみコードの形

プリントの写真から Claude が作る JSON。アプリの「せってい」→「とりこみ」に貼る。

```json
{
  "manabi": 1,
  "items": [
    { "type": "test", "subject": "理科", "title": "電気のはたらき 小テスト", "range": "教科書 p.40〜52", "date": "2026-11-10" },
    { "type": "homework", "subject": "国語", "title": "漢字ドリル p.12〜15", "date": "2026-11-04" }
  ],
  "quizzes": [
    {
      "title": "電気のはたらき",
      "subject": "理科",
      "questions": [
        { "q": "電池を直列つなぎにすると、モーターの回る速さは？", "options": ["速くなる", "おそくなる", "変わらない"], "answer": 0 },
        { "q": "1.5V のかん電池2こを直列につなぐと何ボルト？", "answer": 3 }
      ]
    }
  ]
}
```

- `type` は `test`・`homework`・`goal`（目標）、`date` は `YYYY-MM-DD`
- 選ぶ問題は `options` と、正解の番号（0から）を `answer` に書く
- 数字で答える問題は `options` を書かず、`answer` に整数を書く
