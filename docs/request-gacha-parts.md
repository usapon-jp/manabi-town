# 3Dセッションへのお願い: パーツガチャで出たものを箱庭に置けるようにする

まなびタウンに「パーツガチャ」を入れました（画面は `js/gacha.js`、中身の表は `js/data/gacha.js`）。
子どもはポイント100をガチャ石1こにこうかんし、石1こで1回ひきます。
出たものは今は「あつめたパーツ」に並ぶだけなので、3D側で **置く・うえる** をお願いします。

## 読みとり口（js/gacha.js）

| 関数 | かえすもの | 使いみち |
| --- | --- | --- |
| `ownedParts(p)` | `{ itemId: こすう }`（たてる・かざる） | どうぐぶくろに並べる。**置いた数は箱庭の保存から引いて**、のこりを出す |
| `ownedSeeds(p)` | `Set` of 花の種類（`plants.js` の `SPECIES` のキー） | 「花のタネ」の道具でえらべる花をふやす。今の5種類は最初から使える |
| `ownedCharas(p)` | なかまの項目の並び（`cat: 'chara'`） | 街に住ませる（今は0人。あとで足す） |
| `itemById(id)` | 項目（名前・★・`size`・`color`・`svg`） | どうぐぶくろの絵・名前 |

- id は保存に使うので変えません。知らない id は読みとばしてください（古い版・未対応のもの）。
- 置いた・しまったは箱庭の操作（`place / move / remove`）として保存し、元に戻せるように。魔法のロープでリセットしたときは、どうぐぶくろへ戻す（`request-magic-rope.md` と同じ考え）。

## 置き方（プロジェクトの決めごとにあわせる）

- **たてる**（`cat: 'build'`）: マスにすいつく・90度ずつ回す。柵・ひさし・家・橋・アーチ
- **かざる**（`cat: 'decor'`）: 自由に置く・自由に回す。ランタン・ポスト・植木ばち・ベンチ
- **うえる**（`cat: 'seed'`）: 新しい花の種類。刈った所だけにうえられる
- ものさし: キャラ1m・ドア1.5m・小さい家ののき1.9m/てっぺん3〜3.5m・柵0.5m・家具は1.2倍

## あとから足すもの

- **なかまキャラ**: `js/data/gacha.js` の `ITEMS` に `cat: 'chara'` の行を足し、`BANNERS` の `items` に入れるとガチャから出ます。3D側は `js/characters.js` にモデルを足して、`ownedCharas(p)` に入っている子を街に出してください。
- **季節の台・テスト後イベントの台**: `BANNERS` に `from` / `to`（YYYY-MM-DD）つきで足せば、その期間だけ画面にタブが出ます。
- **きらきら**: タネ・なかまがかぶると たまります（`kira(p)`）。使い道（建物のレベル上げ・色ちがいなど）は未定。
