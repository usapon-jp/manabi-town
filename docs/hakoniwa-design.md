# 箱庭（つくる）の設計メモ — 理想と、今の実装からの発展のさせかた

目指す姿: **シンプルな道具と操作だけで、自由に自分の世界を作れる**。
草刈り機で道、草の種で草原にもどす、丸く刈って花を植えて花壇、レンガ・丸太でかこむ、スコップで掘って池につなげると川、
道具はレベルで解放、花はガチャでふやす、道具は画面右のアイコンを上にスワイプして持ちかえ、将来は建物・柵・家具・小物も置ける。

## 今の実装（2026-11 時点）

- 保存: プロフィールの `p.world.ops`（操作の並び）。見た目は「操作を先頭から再生」してつくる。取り消し＝最後の操作を捨てて再生しなおし。
- 地面の記録: `js/cutmask.js` の 256×256 の絵（赤＝みち、緑＝花だんの土、青＝ほった所）。ほり深さだけ CPU にも同じものを持つ。
- 花: `js/plants.js` に5種類を手書き。野原の分と、子どもがうえた分（`createPlantLayer`）。
- かこみ: `js/builds.js`（丸太／石を線にそってならべる）。
- 画面: `js/editor.js`（右に「つくる」の縦ボタン、下に小さな道具ぶくろ）。

## 理想とぶつかる所（早めに直したい順）

1. **草を「もどせない」**: 地図は重ね塗り（明るいほうが勝つ）なので、あとから消せない。→ 操作を**順番どおり**に適用し、「草の種」は赤だけを消す塗りにする。
2. **水がどこでも出る**: 今は掘ればすぐ水の色になる。理想は「池につながったら流れる」。→ 青は**深さだけ**にして、水は「池からつながった掘り」を CPU で調べて決める（下の「水」）。
3. **花が刈った範囲に縛られない／1本ずつ抜けない**: いまは草の上にも植えられる。→ CPU にも「刈った所」の地図を持ち、植えられるのはそこだけ。抜く操作（消しゴム）を追加。
4. **地面の種類が色チャンネル直書き**: レンガ・砂などがふえると足りない。→ 「地面の種類の番号」の地図に一般化（下の「地面」）。
5. **花が手書きコード**: ガチャでふやせない。→ 花を「型＋数値」のレシピにする（下の「植物」）。
6. **道具がボタンの直書き**: レベル解放・スワイプ持ちかえに向かない。→ 道具の登録表にする（下の「道具」）。
7. **保存が本体データの中**: ふくらむと全体の保存が重い。`store.js` はバージョンが変わると中身を空にする作りで、箱庭が一緒に消えるおそれ。→ 箱庭は**別の保存キー**に分ける。
8. **操作は最大300・圧縮なし**: 長く遊ぶと再生が遅くなる。→ 古い操作を「焼きこみ」（下の「保存」）。
9. **建物は `town.js` のレベル固定位置**: 子どもが置く建物と両立しない。→ 設置物（エンティティ）に移す。ただし建物の方向性が決まるまで着手しない。
10. **花の種類ごとに描画が2つ**: 種類がふえると重い。→ 型ごとにまとめる。

## 設計

### 地面（Surface map）
- 0.25m ごとのセルに「種類の番号」と「ほり深さ」を持つ（見える方眼にはしない。見た目はなめらかにぼかす）。
- 種類: 草 / 土の道 / 花だんの土 / レンガ / 砂 / …（番号で追加できる。2枚目のテクスチャで8種類以上に）。
- 画面側は今のシェーダー方式のまま。CPU 側にも同じ配列（8bit）を持つ → 「植えられるか」「置けるか」「歩けるか」を即答できる。
- 操作は `{t:'paint', surface:'dirt', mode:'add'|'remove', pts, r}` のように**種類を引数**にする（いまの `path` は `paint dirt add` の別名として読みつづける）。

### 水
- 池は「水源」。掘った溝のうち、水源から**つながっている所**だけ水になる（幅優先で塗りつぶし。256² なので数 ms）。
- 水源からの距離を地図に入れれば、流れの向きも出せる（水面のゆらぎを流れ方向に動かす）。流体シミュレーションは不要。
- つながっていない溝は、湿った土のくぼみのまま。つなげた瞬間に水が流れこむ演出（距離順に広がる）が作れる。
- 既存のレベル3の池は水源にできる。子どもが掘る「いけ」も水源。

### 湧き水（同じ場所を3回掘ると水が湧く）
- スコップで**同じ場所をなぞるたびに、すこしずつ深くなる**（1回目: しめった土、2回目: どろのくぼみ、3回目: 水が湧く）。1回のなぞりは1段だけ（なぞりの中で重なっても1回と数える）。
- 3段目に届いた所が**水源**になる。小さければ**井戸**（石のふちがつく）、広く掘れば**池**。水源につながった溝は、水が流れこんで**川**になる。
- 池ツール（かこんで掘る）はいらなくなる。広い筆で3回掘れば池、という1つの道具にまとめられる。
- 深さは「0〜3の段」で持つ（今は1回で最大の深さ）。各段の見た目＝土の湿り方・どろ・水。**「うめる」**（段をもどす）と、取り消しの両方でやりなおせる。
- スコップの強化（レベル解放）で「2回で湧く」などにもできる。
- 掘った所の花は消える（消しゴム操作と同じ扱い）。

### 植物
- 花は**レシピ**: `{id, family:'cup'|'spike'|'daisy'|'puff'|'clover', 色, 大きさ, 高さ, 葉, 花びら数 …}`。ガチャは「レシピをふやす」だけ。
- 保存は `species` の **id 文字列**。知らない id（古い版・未解放）は読みとばす → 後から種類をふやしても壊れない。**id は変えない**。
- 描画は family ごとにまとめた InstancedMesh（色・大きさはインスタンス単位）。種類がふえても描画数は family 数で止まる。
- 植えられる場所は CPU の地面地図で判定（刈った所だけ）。「線」＝なぞる、「面」＝範囲塗り（密度つき）。
- 抜く: 消しゴム操作（`erase`）を順番どおり適用。インスタンスは削除に強い持ち方（入れかえ削除）にする。

### 道具
- 登録表: `{id, icon, unlockLevel, options(太さ・種類・かこみ素材), onPointer}`。
  草刈り機 / 草の種 / じょうろ（のちに成長）/ 花の種 / 囲い（レンガ・丸太）/ スコップ / 消しゴム / 設置（のちに）。
- 持ち替え: 画面右のアイコン（いまの道具）を**上にスワイプ**で、ほかの道具が縦にならぶ。ぶれない指の動きで選ぶ。ロックされた道具は鍵つきで見せて、解放レベルを表示。
- 解放は `profile.world.unlocked`（道具・花レシピ・囲い素材）。レベルから計算できるものは保存しない。
- 参考（原神）: 手に持っている道具のアイコンの上に「︽」が出ていて、上にスワイプすると、大きな丸いアイコンが画面なかほどに1列にならぶ。指をはなすと決定。ならぶ数は少なく（4つほど）、選んだものだけ強調する。
- 右側のダッシュ・ジャンプと近いので、道具アイコンはそのすぐ上に置く（スワイプ領域を確保）。

### 設置物（将来）
- エンティティ `{id, type, x, z, rot, scale}`。操作は `place / move / remove`。型ごとに InstancedMesh、当たり判定は半径1つ。
- 置けるか: 地面地図（水・掘り・道の上を避ける）＋ 他の設置物との重なり。回転・移動・撤去で取り消し可能。
- 今の `town.js` の建物は、初期配置のエンティティとして読みこむ形に変える（子どもが動かせる）。

### 保存・取り消し・軽さ
- 保存キーを分ける: `manabi-world-<profileId>`。書きこみは操作のたび（ゆるいデバウンス）。`v` を持ち、移行コードを書けるようにする。
- 取り消し: 直近 N（50〜100）操作。**焼きこみ**: 古い操作は、地面地図（RLE 圧縮）＋設置物の一覧にまとめて「基準」に移し、取り消しできる範囲だけ操作として残す。
- 再生コスト: 1操作ずつ差分適用（いまは毎回ぜんぶ再生）にして、長い再生を避ける。
- 軽さの目安: 描画 150 回以内、三角形 50万以内を目標に、起動時に簡単な計測（フレーム時間）で「草の本数」「地面の細かさ」を段階で下げる。
- いまの地面は約0.5m・3.3万頂点、草2.6万本。実機で重ければ、地面を粗く（0.65m）し、草を減らすのが最初の手。

## 段階

| 段階 | 内容 | いまの実装に対して |
| --- | --- | --- |
| A 土台 | 箱庭の保存を別キーへ（移行つき）／道具の登録表／順番どおりの適用／CPU 地面地図 | 保存の場所と editor の作りを替える。ops の形は読みつづけられる |
| B 刈る・もどす・植える | 草の種（もどす）／刈った所だけに植える／面で植える／消しゴム／レンガ・丸太の囲い（花壇の仕上げ） | `path`・`ring`・`plant` を引きつぐ |
| C 水 | スコップ／池からつながった溝だけ水／流れの向き | `dig`・`pond` を引きつぐ（水の出しかたが変わる） |
| D 解放とガチャ | レベル解放／花レシピ化／ガチャ／スワイプで道具持ちかえ | 花を5種から増やせる形にする |
| E 設置物 | 建物・柵・家具・小物の自由配置／`town.js` の移行 | 建物の方向性が決まってから |
| F 長く遊ぶ | 焼きこみ／品質の段階 | A〜D のあと、操作がふえてから |

いま作った「みち・花壇・川」は捨てずに、A〜C で**読み方を引きつぎながら**置きかえられる。

## まちのピヨ（つかいかたの しつもん）との約束

ホームの「きょうやること」の となりの ピヨ（js/townask.js）は、まちづくりの つかいかたを js/townguide.js の GUIDE を読んで答える。
3Dの操作・ボタン・道具を かえたら、**js/townguide.js の GUIDE と SHOW（光らせる ボタンの セレクタ）も いっしょに直す**（受け口のデプロイは いらない）。
子どもの しつもんは manabi_feedback に screen = 'まち:しつもん' で のこるので、チュートリアル・ヒントを 考えるときの 材料にする。
